# Бесплатное размещение: Cloudflare Workers + D1

Cloudflare позволяет разместить интерфейс и API на Workers, а общие лиды хранить в D1. Бесплатный лимит Workers — 100 000 запросов в сутки; у D1 есть суточные лимиты чтения и записи. После достижения лимитов операции могут временно перестать выполняться до сброса квоты. Бесплатный тариф подходит для небольшого проекта, но не гарантирует непрерывную работу при превышении квот.

## Что потребуется

1. Аккаунт Cloudflare и установленный Wrangler (`pnpm install`).
2. Создать D1 базу `liniya-crm`, получить её ID и вписать его в `wrangler.toml` вместо `REPLACE_WITH_D1_DATABASE_ID`.
3. Выполнить `pnpm db:migrate:remote` и `pnpm deploy`.
4. Задать секреты: `pnpm wrangler secret put ADMIN_PASSWORD`, `SESSION_SECRET`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_WEBHOOK_SECRET`.
5. Войти в опубликованную CRM и выбрать «Настроить Telegram».

Не публикуйте пароль и токен бота в репозитории или сообщениях.

В этой папке подготовлен отдельный Cloudflare Worker, но он не опубликован автоматически: у текущего процесса нет авторизованной учётной записи Cloudflare и ID созданной D1 базы.
