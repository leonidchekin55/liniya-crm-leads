# Линия — CRM заявок агентства

Публичный MVP для Render: рабочее пространство с паролем, общей базой лидов, ручным добавлением, поиском, тегами, статусами и заявочным Telegram-ботом.

## Сценарии MVP

- Бот по шагам собирает имя, контакт и запрос. Перед сбором данных он сообщает, что заявка будет передана в CRM агентства. После последнего шага лид с тегом «Новый» сразу появляется в общей очереди.
- Менеджер вручную добавляет лид и назначает тег.
- Теги можно создавать, назначать лидам и использовать для фильтрации.
- Доступ к CRM закрыт паролем; публичная ссылка не открывает контакты и заявки посторонним.
- Подключение личного аккаунта Telegram сознательно не включено в MVP. В исходном наброске описан путь через Telegram Business API и его ограничения.

## Публикация

`render.yaml` поднимает Node.js web service и отдельную PostgreSQL базу в регионе Frankfurt. Переменные `SESSION_SECRET` и `TELEGRAM_WEBHOOK_SECRET` генерируются Render. В настройках сервиса нужно указать `ADMIN_PASSWORD` и токен выделенного бота в `TELEGRAM_BOT_TOKEN`. После публикации войдите в CRM и нажмите «Настроить Telegram».

В этой учётной записи уже занята единственная бесплатная база Render, а бесплатные базы ограничены сроком хранения. Для отдельной базы проекта манифест использует `basic-256mb` по текущей цене Render $6/месяц плюс стоимость хранения. Публичный бесплатный web service засыпает после периода без запросов; Telegram-webhook может сработать с задержкой после такого простоя. Для постоянного приёма заявок без задержек нужна платная база и постоянно работающий web service.

## Локальный запуск

Требуются Node.js 22+ и PostgreSQL. Установите зависимости и настройте переменные окружения `DATABASE_URL`, `SESSION_SECRET`, `ADMIN_PASSWORD` и `TELEGRAM_WEBHOOK_SECRET`. `TELEGRAM_BOT_TOKEN` можно оставить пустым для проверки CRM без Telegram.

```sh
pnpm install --frozen-lockfile
pnpm start
```

Таблицы, индексы и начальные теги описаны в `db/schema.sql`. База хранит заявки между перезапусками приложения. Telegram updates дедуплицируются, webhook защищён отдельным секретом.
